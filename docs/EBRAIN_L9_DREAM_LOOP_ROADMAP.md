## 1. 这份路线图解决什么问题

当前仓库的 `L9 Alpha` 已经存在，但它更像一个：

- lease-governed loop core
- candidate / forecast / critique 结构输出层
- stop-reason 与 budget clamp 骨架
- protective turn 的认知闭环中段

它已经可用，但距离“真正的梦环场”仍有明显差距：

- 还没有真正的候选前沿治理
- 还没有显式的不确定账簿
- 还没有显式的证据债对象
- 还没有结构化的后果地形与反事实分岔
- 还没有主权断点进入环内的第一等对象
- 还没有对 `L10 / L11 / L12 / L13 / L14` 的完整可消费产物面

所以这份路线图的目标不是“立刻重写 L9”，而是：

1. 维持当前 repo 的口径诚实
2. 让 `Finite Dream Orbit Field` 成为明确终局
3. 采用低风险、可兼容、可回放、可预算治理的迁移路线

## 2. 固定执行口径

### 当前仓库口径

`L9 Alpha = BASThoughtFrame + candidate/forecast/critique + BASCandidateFrontier + BASCounterfactualBundle + BASCritiqueBundle + loop budget clamp + protective turn`

### 目标态口径

`L9 v∞ = Finite Dream Orbit Field / 有限认知环流场`

### 迁移策略

迁移策略固定为：

- additive schema enrichment
- compatibility projection
- runtime main-chain gradual takeover

也就是说：

- 保留 `BASThoughtFrame` 作为兼容运行时主载体，不直接退役
- 新增一层 `ThoughtLoopState -> BASThoughtFrame` 的安全投影
- 让当前 `CandidateFrontier / CounterfactualBundle / CritiqueBundle` 逐步退化为目标态对象族的兼容桥
- 新的深层梦环逻辑由 `frontier / uncertainty / evidence debt / convergence / sovereign breakpoint` 对象族承担

这条路线避免一次性切断当前主链，也避免把 `BASThoughtFrame` 强行膨胀成什么都装的巨型对象。

## 3. 设计原则

### 3.1 先并行，再迁移

`ThoughtLoopState` 与相关对象族先并行存在，先做到：

- schema 清晰
- mapping 明确
- compatibility 可测

然后才逐步进入 runtime、memory、risk、replay、surface。

### 3.2 current repo truth 优先

当前 repo 已经落地的事实，不能被目标态文档抹平：

- `BASThoughtFrame` 仍是主链认知环的权威 runtime 载体
- `BASCandidateFrontier / BASCounterfactualBundle / BASCritiqueBundle` 已进 schema governance
- `BASRunLease` 与 budget clamp 已经真实约束 `L9`
- `L9` 当前状态仍是 `Alpha`，不是 `v1 shipped`

### 3.3 L9 永远受 `L1 / L11 / L14` 约束

路线图中所有阶段都必须坚持：

- `L9` 不能越过 `RunLease`
- `L9` 不能绕过 `L11 风闸` 直接把候选变成行动
- `L9` 不能绕过 `L14 玄戒` 延迟执行主权断支

### 3.4 多路径优先于长文本

未来 `L9` 的增强方向，不是“更多内部文字”，而是：

- 更好的候选差异
- 更好的反事实结构
- 更好的守护枝
- 更好的停环治理

### 3.5 继续思考权必须被治理

继续想不是默认权利，而是预算内的局部特权。  
这意味着：

- 每轮都有收益判断
- 每个新增候选都有宽度成本
- 每种投影都有租约成本
- 每次主权预警都可以要求缩环、切枝、冻结、止环

## 6. 目标架构轮廓

### 6.1 并行的梦环对象族

目标态对象族建议固定为：

- `ThoughtLoopState`
- `CandidatePath`
- `CandidateFrontier`
- `CounterfactualBranch`
- `OutcomeProjection`
- `AdversarialBrief`
- `HostAlignmentMap`
- `UncertaintyLedger`
- `EvidenceDebt`
- `ConvergenceCertificate`
- `LoopLeaseReceipt`
- `SovereignBreakpointHint`

这些对象在 `Phase 0` 之前都仍是文档与路线图概念，不是当前仓库已治理 schema。

### 6.2 双层运行时接口

目标态服务接口采用“双层制”：

#### `ThoughtLoopState` 层

负责：

- 候选前沿
- 反事实分岔
- 后果地形
- 反方简报
- 不确定账簿
- 证据债
- 收敛证明
- 主权断点提示

#### `BASThoughtFrame` 层

保留，但职责收缩为：

- 为旧主链提供兼容 runtime 摘要
- 为 replay / export / flight deck 提供已存在消费面
- 暂存旧接口消费者的运行时契约

### 6.3 兼容投影层

需要一层显式 projection，把目标态对象安全投影成：

- `BASThoughtFrame`
- `BASCandidateFrontier`
- `BASCounterfactualBundle`
- `BASCritiqueBundle`
- 现有 `summary / replay / export` 摘要线

投影层的职责不是复制全部梦环内容，而是：

- 压缩成现有主链需要的最小摘要
- 保持版本可追溯
- 对当前主链保持可回放兼容

### 6.4 downstream 可消费面

目标态 `L9` 必须形成以下下游消费面：

- `L10`：候选与 veto-ready material
- `L11`：可逆性、证据债、守护枝、反方增益
- `L12`：表达模式选择
- `L13`：可学习的结构骨架
- `L14`：可切枝、可缩环、可止环的主权断点面

## 7. 分阶段路线

### Phase 0 `repo-real`

#### 目标

冻结文档结构、命名、现状口径与迁移策略。

#### 交付物

- `L9 v∞` 白皮书
- `L9` 总路线文档
- 执行总纲、附录、README 中的统一口径补丁

#### 依赖

- 当前 repo 的 `L9 Alpha` 现状
- 已有 `L4 / L5 / L6 / L7 / L14` 的 target-state 文档风格

#### 退出门

- 文档明确区分 current / target
- 所有目标态对象都标为 documentation-only
- 没有把未来路线误写成当前 shipped capability

#### 非目标

- 不新增 runtime schema
- 不新增 service contract
- 不改现有主链代码

### Phase 1 `additive schema spine`

#### 目标

建立并行 `L9` 核心对象脊柱，但不打断当前主链。

#### 交付物

- `UncertaintyLedger`
- `EvidenceDebt`
- `ConvergenceCertificate`
- `SovereignBreakpointHint`
- `LoopLeaseReceipt`
- `CandidateFrontier v2` additive fields
- mapping / backward / rollback 测试位

#### 依赖

- 当前 `BASThoughtFrame / BASCandidateFrontier / BASCounterfactualBundle`
- 现有 schema governance 机制
- `BASRunLease` 已存在的预算外壳

#### 退出门

- 新对象已进入 schema governance
- `BASThoughtFrame` 兼容投影仍可回放
- replay/export 不因 additive 字段破坏旧链路

#### 非目标

- 不重命名或移除 `BASThoughtFrame`
- 不要求一次性完成真实多路径 runtime
- 不把不确定账簿与证据债直接暴露成产品 UI 的原始对象

### Phase 2 `runtime orbit enrichment`

#### 目标

把当前 loop 从“轻量循环推理引擎”推进到“有限梦环场”的可运行雏形。

#### 交付物

- 真正多路径候选前沿
- `guard branch` 生成与 takeover 逻辑
- 结构化 `CounterfactualBranch`
- `OutcomeProjection` 地形化字段
- `stop mode` 明确区分：
  - `converged`
  - `lease_end`
  - `sovereign_cut`
  - `guard_takeover`
- `L1/L14` 约束进入环内的 shrink / cut / freeze / stop 行为

#### 依赖

- `Phase 1` 对象脊柱
- `L7` 的更干净 canonical inputs
- `L11` 的风险模式与 permit 需求
- `L14` 的断点与 actuation 语义

#### 退出门

- 至少 3 类结构不同候选可并生
- 高风险场景守护枝存在率可测
- stop-mode 区分不再只靠文案语义
- 主权预警能造成真实的缩环或止环

#### 非目标

- 不追求完整训练闭环
- 不追求一次性完成所有场景的深环最优策略
- 不把长文本内部推理当作主要能力指标

### Phase 3 `downstream adoption`

#### 目标

让目标态 `L9` 产物真正被 `L10 / L11 / L12 / L13 / L14` 消费，而不是只存在于内部结构里。

#### 交付物

- `L10` 消费 candidate frontier / adversarial brief / host alignment
- `L11` 消费 reversibility / evidence debt / uncertainty / guard branches
- `L12` 消费 stop mode / guard takeover / delay path / compare mode
- `L13` 消费 reusable loop skeletons，而不是长文本 reasoning
- `L14` 消费 sovereign breakpoint hints 并反向控制梦环

#### 依赖

- `Phase 2` 的 runtime orbit enrichment
- 下游层的兼容投影面

#### 退出门

- `L10-L14` 至少各有一个真实消费点
- replay/export/flight deck 可以讲清 `L9` 是怎样收环的
- 宿主层不会被 `L9` 的“最优路径”夺权

#### 非目标

- 不要求所有下游层一次性全面改用目标态对象
- 不要求产品 UI 暴露所有中间结构

### Phase 4 `training, distillation, mobile closure`

#### 目标

把目标态 `L9` 从工程骨架推进到适合移动端的稳定能力。

#### 交付物

- 候选前沿课程
- 后果地形课程
- 反事实分岔课程
- 反方法庭课程
- 不确定账簿课程

## 9. 测试与治理要求

### Schema 治理

- 为所有新 `L9` 对象补 `current / backward / rollback` 测试
- `BASThoughtFrame` 兼容投影必须保持可回放
- 明确哪些对象已进 registry，哪些仍是 roadmap-only

### 运行时兼容

- live turn / checkpoint / replay / export / surface 的 `L9` 摘要必须一致
- additive 变化不能破坏当前 `BASThoughtFrame` 消费方

### 多路径真实性

- 表面 3 路候选不能其实只是 1 路改写
- 必须跟踪 frontier diversity，而不是只统计 candidate count

### 主权约束

- `L9` 不能绕过 `L14`
- 主权断点命中后必须可测地 shrink / cut / freeze / stop

### 风险与守护

- 高风险场景必须有守护枝
- 守护枝不是文案替身，而是结构不同的路径

### 诚实度

- 证据债不能被“逻辑顺”掩盖
- 不确定账簿不能因循环轮数增加而自动消失

### 产品体验

- 检查“更稳而不是更长”
- 检查“更深但不拖”
- 检查“更会反驳自己但不瘫痪”
- 检查“保留宿主主体性”

## 10. 当前仓库明确不宣称的能力

- `L9` 已经从 `Alpha` 进入 fully shipped `v1`

## 11. 最终路线定义

把这份路线图压成一句最准确的话：

`L9` 的 repo-real 演进，不是把 `BASThoughtFrame` 写得更大，而是以 additive、兼容、受预算与主权约束的方式，把当前 `Alpha` 梦环骨架逐步推进为真正可治理的 `Finite Dream Orbit Field`。

再压成一条白皮书级路线定义：

它的目标不是让系统“想更久”，而是让系统在主链可承受的租约内，形成更稳的候选结构、更诚实的不确定记录、更可靠的守护路径，以及在主权命令到来时真正会缩环、会断支、会停的思维器官。
