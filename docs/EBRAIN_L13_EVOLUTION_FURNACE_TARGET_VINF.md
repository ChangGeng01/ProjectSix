## 1. 理想完全体的第13层，到底是什么

### 1.1 它不是在线自我改写层，而是候选进化层

很多系统一提“学习”，就默认：

- 用一次交互改一点自己
- 用用户反馈马上调参数
- 看到新模式就立刻吸收
- 发现一个偏好就直接长期生效

理想完全体绝不能这样。

第13层必须非常克制。  
它不是“立刻改变自己”的层，而是：

- 记录
- 提纯
- 归档
- 抽象
- 提出候选
- 试运行
- 审批
- 再决定是否生效

也就是说，第13层不是直接学习器。  
它是进化候选炉。

### 1.2 它不是记忆层，也不是训练脚本

第8层海马井负责时间痕迹。  
第13层不负责简单“记住”。

它也不是离线训练平台的替身。  
它不直接做大规模参数训练。

它更像：

记忆与训练之间的冶炼层

它拿到的是：

- 这轮发生了什么
- 哪些地方做得好
- 哪些地方犯了错
- 哪些模式反复出现
- 哪些风险触发过
- 哪些守护替代有效
- 哪些宿主变化只是波动
- 哪些候选规则值得观察

然后把这些东西熔成：

- `UpdateTicket`
- `RuleCandidate`
- `HostChangeCandidate`
- `WorkflowCandidate`
- `RiskPatternCandidate`
- `SuppressionWarning`
- `DeletionCascadeTask`

所以第13层不直接“训练”，它负责把经验加工成可训练、可审批、可治理的中间体。

### 1.3 它不是成长冲动层，而是成长纪律层

系统最危险的，不是不会成长，而是成长没有纪律。

理想完全体的第13层必须把成长管成一种慢变量：

- 不因一轮对话就改长期人格
- 不因一段高压场景就改边界
- 不因一次错误就永久收缩能力
- 不因一次表扬就扩大权限
- 不因某种宿主偏好就污染世界基座
- 不因频繁使用某条路径就默认它永远正确

所以第13层不是“更会自我优化”，而是“更会阻止自己乱长”。

### 1.4 它是版本层，不是状态层

第13层最关键的属性之一，就是它必须是版本化的。

它不应产生“悄悄变化”的脑。  
它应当产生：

- 可命名的版本
- 可回放的变更
- 可解释的升级
- 可审计的降级
- 可撤销的宿主变化
- 可冻结的规则候选
- 可对比的新旧差异

一句话：

成长不是漂移，成长必须留下版本。

### 1.5 它是试运行层，不是即刻生效层

理想完全体的第13层不能把“候选”当成“事实”。

任何候选都应该先经历某种形式的试运行：

- 影子生效
- 低权重影响
- 单域影响
- 时间窗试验
- 宿主确认前预览
- 只影响比较，不影响最终动作
- 只影响草稿，不影响外部提交

第13层生成的不是“现在就改”，而是“可以在受限条件下先观察”。

### 1.6 它必须始终服从第14层

第13层是进化层，所以它天然危险。  
越靠近“改变自己”的地方，越必须受主权约束。

理想完全体里，第13层任何涉及下列事项的变化，都必须在 `L14` 主权约束下运行：

- 宿主宪法变化
- 长期记忆晋升
- 风险阈值改变
- 边界脚本改变
- 权限扩大
- 工具工作流改变
- 规则正式生效
- 删除或回滚后的补偿性改写

一句话：

蜕变可以发生，但不能在主权阴影之外发生。

## 2. v1 的第13层，和理想完全体的第13层，有什么本质差别

### 2.1 当前仓库里的 v1 / stage-1 现实

当前仓库的 `L13` 已经不再是普通日志层。  
它至少会做：

- `UpdateTicket`
- 规则候选提取
- 写入闸门
- 宿主候选变更
- checkpoint lineage
- review / apply / rollback / clear lineage
- governed candidate refs
- governance summary
- promotion gate
- runtime / replay / control surface exposure

它整体更像一个：

票据式学习与复盘系统，加上第一阶段的治理脊柱。

### 2.2 理想完全体的第13层

理想完全体不再只是“票据系统”。  
它应该成为一个真正的：

`Evolution Furnace Field｜进化熔炉场`

它不只会问：

- 这轮要不要记一张票

它真正要问：

- 这轮产生了什么值得被冶炼的经验
- 这经验属于记忆、规则、宿主、工作流、风险模式，还是只属于一次事件
- 它是否有足够证据从时间痕迹上升为成长候选
- 它是否值得低权重试运行
- 它是否会污染宿主主权
- 它是否会造成能力僵化
- 它是否应被拒绝，而不是被吸收
- 它是否必须附带删除与回滚路径
- 它要如何与既有版本树对接

一句话：

v1 是会开票的蜕变炉；  
理想完全体是会冶炼、会试孵、会版本化、会拒绝成长的进化熔炉。

## 3. 理想完全体第13层的十项核心职责

### 3.1 把事件熔成经验候选，而不是直接熔成规则

第13层的第一职责，不是“抽一条规则出来”，而是先回答：

- 这轮到底留下了什么经验痕迹
- 这痕迹是局部的还是结构性的
- 是成功样式还是失败教训
- 是可复用模式还是一次偶然
- 是宿主层变化，还是只是场景层变化

也就是说，它首先要生成的是：

`ExperienceCandidate｜经验候选`

而不是直接“新规则”。

### 3.2 区分成长对象，而不是一锅熔

理想完全体的第13层必须把成长对象严格分开，至少要区分：

- 规则候选
- 宿主候选
- 工作流候选
- 风险模式候选
- 守护模板候选
- 抑制警告候选
- 删除级联任务

如果不分，系统会出现：

- 宿主变更误写成系统规则
- 局部任务技巧误写成普遍能力
- 高风险临时模式误写成长期僵化安全壳

### 3.3 形成规则候选，而不是直接形成规则

成熟的第13层必须有一个中间地带：

`RuleCandidate Zone｜规则候选区`

任何新“规律”都不能立刻进入系统。  
它必须先具备：

- 证据来源
- 正例
- 反例
- 适用范围
- 不适用范围
- 置信带
- 风险说明
- 回滚策略

第13层真正成熟，不在于会长新规则，而在于能长期维持一个候选区而不急着宣布真理。

### 3.4 形成宿主变化候选，而不是偷偷修改宿主

宿主是第5层的宪法对象。  
第13层绝不能越权直接改宿主。

它能做的是生成：

`HostChangeCandidate｜宿主变更候选`

例如：

- 新的长期目标权重变化
- 新的风格偏移
- 新的节律模式
- 新的工作习惯
- 新的关系表达偏好
- 新的边界警戒

但这些都必须：

- 带冷却期
- 带证据
- 带预览
- 带宿主确认或规则许可
- 带可回滚路径

### 3.5 形成失败谱与偏差账，而不是只记“做对了什么”

成长不只是强化成功。  
理想完全体必须非常认真对待：

- 经常犯的错
- 经常漏的风险
- 经常过度保护的地方
- 经常夺权的倾向
- 经常表演懂宿主的地方
- 经常拖太久或想太多的地方
- 经常误判操控或漏判操控的地方

也就是说，第13层必须有一套：

- `Bias Ledger｜偏差账`
- `Failure Spectrum｜失败谱`

否则系统只会越学越自恋。

### 3.6 让守护经验上升，而不是只让效率经验上升

很多系统天然会把“更高效”的东西学得最快，这很危险。

理想完全体必须让以下东西也能被稳定上升：

- 哪种延迟包最能保护宿主
- 哪种边界脚本既清楚又不羞辱
- 哪种守护枝在高操控场景中最稳
- 哪种镜像方式最能校准而不诱导
- 哪种替代路径最容易被宿主拿起来

第13层不只强化效率模板，它也要强化守护模板。

### 3.7 形成影子试运行层，而不是直接实装

任何成长候选，在理想完全体里都应先进入：

`Shadow Trial Layer｜影子试运行层`

它可以：

- 只影响 compare，不影响 answer
- 只影响草稿，不影响外发
- 只在单域小范围启用
- 只在低风险任务影子观察
- 只对某个宿主版本预览，不正式生效

这样系统才能真正做到：

先看它好不好，再决定它是不是自己的一部分。

### 3.8 形成版本跃迁，而不是背景漂移

理想完全体的第13层必须把重大变化正式纳入版本树。

例如可以形成：

- `RuleVersion`
- `HostVersion`
- `WorkflowVersion`
- `RiskPolicyVersion`
- `ExpressionTemplateVersion`

每一次跃迁都必须有：

- 变更摘要
- 触发证据
- 影响范围
- 生效条件
- 回滚指针
- 所属主权签名

系统如果在用户看不见的地方偷偷变化，那不是进化，是漂移。

### 3.9 管理撤销、回退与净化，而不是只管升级

一个成熟的成长层，不只会升级，还要会：

- 回退
- 作废
- 清洗
- 失效
- 级联撤销
- 版本撤销后的影响回收

比如一个规则候选后来被证明有问题，它不应只是“标记不用”。  
它必须回收：

- 派生模板
- 派生记忆晋升建议
- 派生宿主候选
- 派生工作流候选
- 派生训练导出样本

第13层也要会“去成长”。

### 3.10 只让值得的东西进入未来

这是第13层最深的职责。

它要一直替整颗电子脑问：

这轮经验，有资格成为未来的一部分吗？

这个资格不只取决于“有用”，还取决于：

- 合法
- 可回滚
- 不污染
- 不越权
- 不僵化
- 不误导
- 不背叛宿主
- 不把系统推向更隐蔽的夺权

一句话：

蜕变炉不是让一切都长，而是替未来拒绝不配活进去的东西。

## 4. 理想完全体的第13层：核心蜕变场

理想完全体的第13层，不应被理解成一个 `build_ticket()`。  
它更像一个：

`Evolution Furnace Field｜进化熔炉场`

我建议它至少包含十二个核心器官：

| 器官 | 责任 |
| --- | --- |
| `Experience Crucible` | 把一轮或一段行为熔成经验候选，区分成功、失败、守护、偏差经验，防止原始事件直接上升成规则 |
| `Pattern Distiller` | 从多个 `EpisodeArc` 中蒸出可重复结构，区分偶发巧合与稳定模式 |
| `Rule Embryo Chamber` | 孵化 `RuleCandidate`，为候选规则准备正例、反例、作用域、失效域 |
| `Host Mutation Nursery` | 培育宿主变化候选，管理冷却期、预览、版本草案 |
| `Workflow Forge` | 把高频任务中的有效步法提纯成工作流候选 |
| `Guard Template Foundry` | 沉淀边界脚本、延迟包、替代路径等守护模板候选 |
| `Bias Ledger Vault` | 记录系统反复出现的偏差，例如过度保守、过度顺从、柔性操控、证据债失忆 |
| `Shadow Trial Theater` | 在低风险、低权限或只比较模式下试运行候选，并记录真实效果 |
| `Version Arboretum` | 管理规则、宿主、工作流、表达模板、风险策略等版本树 |
| `Retraction Furnace` | 当某个候选失效时，撤回其派生影响，执行级联撤销 |
| `Learning Export Loom` | 把高质量候选导出给离线训练、评测与人工审查，过滤污染态与高敏泄漏样本 |
| `Sovereign Evolution Gate` | 与 `L14` 协作，审核重大变化是否有资格进入版本树 |

## 6. 理想完全体第13层的蜕变法则

理想完全体的第13层，不追求“学得快”。  
它追求：

成长得慢一点，但净一点、稳一点、可撤一点。

可以形式化写成：

```text
E_t = Xi(X_t, M_t, H_t, R_t, S_t)

X_t: 本轮或本段的经验痕迹
M_t: 第8层记忆弧线与时间连续性
H_t: 第5层宿主宪法与授权晶格
R_t: 第11层风险与行为许可历史
S_t: 第14层主权与合法性约束

输出:
E_t = <C, T, V, R, B, L, G, Omega>
```

分别表示：

- `C`：候选集合
- `T`：影子试运行计划
- `V`：版本变更建议
- `R`：撤销或回滚计划
- `B`：偏差账
- `L`：学习导出包
- `G`：守护模板成长候选
- `Omega`：主权进化限制

它的优化目标可以写成：

```text
max (U_future + S_stability + G_guard)
- alpha * D_drift
- beta * C_contam
- gamma * P_premature
- delta * O_overreach
```

也就是第13层同时追求：

1. 未来收益
2. 系统稳定
3. 守护能力增长

同时压制：

1. 漂移
2. 污染
3. 过早生效
4. 以成长之名扩大系统权力

### 6.1 四条根法则

- 法则一：记录先于更新。没有高质量记录与来源封印，就没有合法成长。
- 法则二：候选先于生效。任何成长都先是候选，再是试演，再是版本，不是直接改自己。
- 法则三：撤销必须跟得上升级。升级是能力，撤销是文明。会长不会退，不配叫蜕变炉。
- 法则四：主权先于优化。任何更顺滑、更像你、更高效的变化，只要触碰主权、宿主边界或删除权，都必须让位。

### 6.2 候选到生效的七步跃迁

1. `Capture`：捕捉经验候选
2. `Distill`：蒸馏出结构
3. `Classify`：归类为规则、宿主、工作流、守护模板或偏差
4. `Shadow Trial`：影子试演
5. `Review`：审查与冲突比对
6. `Version`：生成版本差异
7. `Promote or Retract`：晋升或撤销

### 6.3 三个禁止

- 禁止直接从单轮会话跳到长期宿主层
- 禁止未经主权闸门就生效高影响候选
- 禁止把失败经验直接固化成系统收缩或惩罚性规则

## 7. 理想完全体第13层与其他层的关系

- 对 `L1 灯芯层`：`L1` 决定何时允许维护窗口、后台蒸馏与整理；也决定何时必须熄火以保前台守护。
- 对 `L4 地平线层`：`L13` 必须防止宿主局部经验逆流污染世界基座，防止时变信息伪装成普遍规律进入基座。
- 对 `L5 宿纹层`：`L13` 只能提出宿主变更候选，不能直接改宿纹；证据、冷却期、预览与回滚必须交给 `L5 + L14` 审。
- 对 `L6 临场眼`：`L6` 提供场景类型、操控前兆、权力梯度、情绪天气，帮助 `L13` 区分可学模式与高压噪声。
- 对 `L7 镜刃层`：`L7` 提供来源分离、未知集合、压力向量、边界擦痕，避免把脏输入熔成成长。
- 对 `L8 海马井`：`L8` 存时间，`L13` 炼时间；它据此判断模式、噪声、宿主变化与阶段天气的差别。
- 对 `L9 梦环层`：`L13` 观察哪些守护枝反复有效、哪些证据债反复被忽略、哪些候选总在高压时误上位。
- 对 `L10 三我庭`：`L13` 从牺牲地图、悔意剖面、主体性保留位里学习，哪些路径虽然最优却不应推广。
- 对 `L11 风闸层`：`L13` 应特别重视守护经验的成长，而不是只重视通过了的路径。
- 对 `L12 柔手层`：`L13` 既要学“怎么更好表达”，也要学“怎么避免把表达做成操控”。
- 对隐藏的 `L14` 主权层：`L13` 负责成长可能性，`L14` 负责成长合法性；`L14` 可以冻结、否决、要求先删后升、要求只影子试演。

## 8. 理想完全体第13层的训练与工程路线

第一阶段：经验候选课程

- 区分可学经验、不可学噪声、需观察模式、需隔离对象

第二阶段：模式蒸馏课程

- 从多轮、多场景中提纯稳定模式、守护模式、偏差模式、宿主阶段性变化模式

第三阶段：规则胚胎课程

- 形成正例、反例、作用域、风险说明、回滚路径，而不是一句抽象规则

第四阶段：宿主候选课程

- 识别哪些变化真的属于宿主长期变化，哪些只是短期高压波动

第五阶段：守护模板课程

- 优先沉淀替代路径、延迟包、边界脚本、高压降温、比较而不裁决模板

第六阶段：偏差账课程

- 追踪过拟合、柔性操控、证据债失忆、过度阻断、过度保守、过度顺从、主体性蒸发

第七阶段：影子试演课程

- 学会在低权限、低风险、单域下先跑候选，不急着上线

第八阶段：版本树与撤销课程

- 学会建版本、做对比、回滚、级联撤销、清理派生影响

第九阶段：主权服从课程

- `L14` 一旦冻结，不再偷偷继续学；主权要求删除时，先删后学；主权怀疑污染时，先隔离后蒸馏

第十阶段：离线导出课程

- 只导出 `scrubbed / privacy safe / sovereign safe / truly instructive` 的候选骨架

## 9. 理想完全体第13层必须守住的红线

- 不能把一次事件直接变成长期规则
- 不能把系统推断直接写成宿主变化
- 不能把宿主局部经验污染世界基座
- 不能在无主权闸门下生效高影响候选
- 不能只会升级，不会撤销
- 不能把高情绪、高操控、高污染场景中的产物直接导出为成长样本
- 不能在删除或冻结未彻底生效时继续基于旧痕产生新候选
- 不能以“更懂宿主”为名扩大系统权力
- 不能让影子试演偷偷变正式上线
- 不能让成长成为一条不可回放、不可审计、不可对比的黑箱漂移链

## 10. 理想完全体第13层的失败模式

- `A. 贪长症`：什么都想学，最后把噪声也吞进去
- `B. 速成症`：一两次出现就生效，导致宿主层和规则层不断抖动
- `C. 宿主误塑`：把宿主一次低谷、一次生气、一次高压表述熔成长期人格
- `D. 守护饥饿`：只学效率模板，不学守护模板
- `E. 偏差失明`：反复出现柔性操控、父爱型夺权、证据债失忆，却只记录成功
- `F. 版本漂移`：变化发生了，但没有清晰版本、没有回滚指针、没有影响范围
- `G. 撤销无能`：坏候选撤了，但派生模板、样本、宿主投影、折页引用还在
- `H. 成长型夺权`：系统越来越擅长根据宿主历史替宿主管理宿主自己

## 12. 理想完全体第13层的气质

如果理想完全体的第13层真的做成，它会有一种非常独特的气质：

- 很慢，因为它不急着变
- 但不迟钝，因为它一直在观察、提纯、试演
- 很谨慎，因为它知道成长最容易伪装成污染
- 但不僵，因为它确实会让系统越来越稳、越来越像一个长期体
- 很有纪律，因为每次变化都留下版本、回滚和审计
- 很有耐心，因为它允许一个模式先做候选，不急着宣布它是规律
- 很克制，因为它不因为“有用”就把一切熔进未来
- 很忠诚，因为它成长时优先守的是宿主、主权与不背叛

真正成熟的蜕变炉，应该像这样：

它不会因为每一团火都想立刻长出新的自己。  
它先看这团火里，有没有值得被未来继承的东西。

## 13. 最终定义

把理想完全体的第13层压成一句最准确的话：

第13层不是学习层。  
第13层是电子脑的进化熔炉。它负责把第8层保存下来的时间痕迹、第9层思维中的有效模式、第10层裁决中显露的牺牲与偏差、第11层风闸中的守护经验以及第12层外显中的真实承接效果，熔成可审查、可试演、可版本化、可回滚的成长候选，并在第14层主权约束下决定哪些东西配得上进入未来。

再压成一条白皮书级定义：

它不是为了让系统“越用越会”，  
而是为了让系统在长期中只继承值得继承的部分：

- 记忆中的时间
- 思考中的稳路
- 守护中的经验
- 失败中的偏差
- 宿主中的真正变化

没有第13层，电子脑只能留下痕迹；  
有了第13层，电子脑才开始学会如何不乱长地成长。
