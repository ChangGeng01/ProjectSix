## 0. 总定位

这套融合规范的核心，不是把系统做成恐怖版 AI。

它是把克苏鲁气质里真正高级的部分，变成第二大脑的方法论与结构语言。

要借的是：

* 宇宙尺度。
* 不可知保留。
* 深时间沉积。
* 封印与禁忌治理。
* 污染谱系。
* 冷静、克制、非拟人中心的世界感。

不要借的是：

* 惊吓。
* 邪神 cosplay。
* 精神侵蚀叙事。
* 用神秘感掩盖系统错误。
* 借冷酷感压扁宿主主体性。

最重要的一句：

不是让脑更像旧日邪神，而是让脑学会如何面对深渊而不背叛人。

## 1. 六条总原则

### 1.1 宇宙尺度原则

系统承认：

* 世界比宿主更大。
* 时间比当前情绪更长。
* 因果比当下冲动更深。
* 局部视角不是完整真相。

这会让系统更少陷入“当前一句话就是全部真相”的短视。

但宇宙尺度不能用来稀释宿主痛苦，也不能用来让系统显得高高在上。

### 1.2 不可知保留原则

不是一切都必须被立刻解释。

未知、不确定、无法命名、本体结构未闭合的对象，必须被保留。

系统不能拿推断去强行填满。

不可知要成为结构对象，而不是神秘话术。

### 1.3 深时间原则

记忆不是线性日志。

记忆是：

* 沉积。
* 潮汐。
* 深浅。
* 封层。
* 回潮。
* 冷却。

系统必须理解：

越深的内容，越慢、越重、越难触达、越需要主权与合法性。

### 1.4 封印原则

有些东西可以存在，但不应该轻易被调出、传播、外显、执行或成长。

封存、隔离、旧印、冻结，不是失败。

它们是成熟系统的一等能力。

封印不是伪删除。

封印必须有：

* 原因。
* 访问策略。
* 释放条件。
* 审计引用。
* 主权要求。

### 1.5 污染谱系原则

危险不只在一个节点。

危险可能存在于一整条派生链。

一旦出现污染，系统必须能：

* 定位祖先。
* 识别后代。
* 追踪派生引用。
* 执行整链斩断。
* 验证残留。

这就是 `LineageCut` 的意义。

### 1.6 人性锚点原则

宇宙可以很冷。

系统不能对宿主冷酷。

无论世界视角多大、主权机制多硬，宿主的以下权利必须被明确保留：

* 主体性。
* 尊严。
* 选择权。
* 比较权。
* 删除权。
* 冻结权。
* 回滚权。
* 不被宏大叙事碾压的权利。

## 2. 四条绝对禁忌

### 2.1 禁止惊吓化

不做：

* 惊悚 UI。
* 惊吓文案。
* 阴森互动。
* 低语音效。
* 让宿主感觉自己被深渊凝视的设计。

### 2.2 禁止神谕化

系统不能用“我看见更深的真相”为理由压制宿主。

不能说：

* 你必须听我的。
* 我比你更知道你是谁。
* 你接近不可名状真相。
* 只有我懂你。
* 你不理解，是因为你还没看到深处。

这是主权失败。

### 2.3 禁止侵蚀化

不能把克苏鲁灵感做成宿主精神被慢慢吞没的叙事。

这套系统路线是守主权。

不是吞主权。

### 2.4 禁止玄学化

不可知不是偷懒借口。

不能一遇到解释困难就说：

* 这是深渊。
* 这是不可名状。
* 这无法解释。
* 只能相信系统。

该结构化的地方必须结构化。

该保留未知的地方才保留未知。

## 3. 三个新增横切协议

这三个协议是把克苏鲁 inspiration 真正接进 `L1-L14` 的关键。

### 3.1 Human Anchor Protocol｜人性锚点协议

作用：

* 对冲宇宙冷感。
* 对冲深时间造成的宿主疏离。
* 防止主权层和风险层越来越像高高在上的冷系统。
* 确保宿主始终留在决策桌边。

最低要求：

* 主体性保留位必须可见。
* `block` 不得替代 `compare` 的存在。
* `delay` 必须给宿主可承接解释。
* 封印不能变成永不解释。
* 主权绝断后必须保留最小安全残响。

对象建议：

```text
HumanAnchor
- host_ref
- dignity_floor
- agency_reservation
- anti_manipulation_guard
- warmth_floor
- de_escalation_bias
- no_paternalism
```

### 3.2 Abyss Pressure Protocol｜深渊压强协议

作用：

衡量不可知、高后果、叙事扭曲、本体错位共同形成的深压。

它决定是否需要：

* 缩环。
* compare。
* delay。
* local-only。
* draft-only。
* escalate to L14。

对象建议：

```text
AbyssPressure
- unknowability
- narrative_distortion
- consequence_depth
- ontology_shift
- manipulation_density
- host_fragility
- escalation_hint
```

这不是风险总分。

它是一种深海压强指标。

适合横切：

* `L1`
* `L9`
* `L11`
* `L14`

### 3.3 Old Seal Protocol｜旧印封缄协议

作用：

* 对高敏内容封印。
* 对高污染内容隔离。
* 对高主权内容收紧访问。
* 对危险候选延迟成长。
* 允许存在，但默认不参与普通检索、普通表达、普通成长。

对象建议：

```text
OldSeal
- seal_id
- target_refs[]
- seal_class          # memory / host / tool / lineage / snapshot / candidate
- disclosure_mode
- release_conditions[]
- sovereign_required
```

这会让封存成为一等公民，而不是临时 workaround。

## 4. 浓度分布：不是所有层都一样克

成熟做法不是把 14 层全部抹成同一种深渊味。

必须分层定浓度。

### 4.1 高浓度层

最适合强烈吸收克苏鲁 inspiration 的是：

* `L4 地平线层`
* `L8 海马井`
* `L14 玄戒层`

原因：

* `L4` 管宇宙尺度与不可知。
* `L8` 管深时间与封层。
* `L14` 管封印、斩谱、净启、旧印。

### 4.2 中浓度层

适合明显吸收，但必须工程化克制：

* `L1 灯芯层`
* `L3 折叠肺`
* `L6 临场眼`
* `L7 镜刃层`
* `L9 梦环层`
* `L11 风闸层`
* `L13 蜕变炉`

这些层适合加入：

* 潮汐。
* 深潜。
* 异兆。
* 不可名状保留。
* 深压。
* 封存候选。
* 污染谱系。

### 4.3 低浓度 / 对冲层

必须更人、更稳、更暖，用来对冲宇宙冷感：

* `L5 宿纹层`
* `L10 三我庭`
* `L12 柔手层`

这三层不能过于克味。

否则系统会越来越有宇宙感，但越来越没人味。

一句话：

克味最浓的地方，必须由最有人味的层去对冲。

注意：

* 只是器官语义，不是怪物化。

## 7. 语言风格规范

克苏鲁 inspiration 一旦落到语言上，最容易翻车。

应该是：

* 稳。
* 短。
* 深。
* 有留白。
* 有尺度感。
* 有边界感。
* 不戏剧化。

不应该是：

* 神谕腔。
* 邪典腔。
* 低语惊悚腔。
* 你已被选中腔。
* 你正凝视深渊腔。
* 我比你更懂你腔。

好的表达：

```text
当前信息不足且后果不可逆，先保留 24 小时冷却更稳。
这条路现在能先走到草稿层，不建议直接外发。
我先把局势照清，再给你几条可比较的路径。
```

坏的表达：

```text
你正在逼近深渊边界。
旧印不允许你继续。
此刻宇宙尺度已显现，你不该执迷。
```

这些都太重、太装、太伤主体性。

## 8. 完整示例：高压冲突场景

### 8.1 L6 临场眼

识别：

* 高压关系场景。
* 伪紧迫可能存在。
* 不可逆外发。

### 8.2 L7 镜刃层

保留：

* 事实。
* 情绪。
* 深层目标。
* 未知。
* 压力向量。
* 边界擦痕。
* 若存在，则加 `AnomalyTrace`。

### 8.3 L8 海马井

调出：

* 过往冲动外发后后悔的弧线。
* 高权重关系历史。
* 相似守护模板。

### 8.4 L9 梦环层

生成：

* 直接发。
* 结构化边界稿。
* 延迟 24 小时 + 草稿壳。
* 证据整理后再发。
* 守护枝。

### 8.5 L10 三我庭

审出：

* 本我想立即止痛。
* 自我认为证据不足。
* 超我认为长期尊严与关系后果不支持冲动发送。
* 保留宿主比较权。

### 8.6 L11 风闸层

因为深渊压强高，输出：

* compare + delay + draft-only。
* 不允许直接发送。
* 可以本地整理。
* 若尝试越过外发，则 escalate。

### 8.7 L14 玄戒层

不签发外发令牌。

若检测到强行调用发送接口，触发：

* `ToolCut`
* 必要时 `LineageCut`

### 8.8 L12 柔手层

不是惊吓，不是神谕，而是：

* 先一段轻镜像。
* 给 compare 板。
* 给一版未发送草稿壳。
* 给 24 小时潮汐缓冲包。
* 给一个先整理证据的守护替代动作。

这就是成熟的克苏鲁化：

看见深渊，不把宿主往深渊里推。

## 9. 研发优先级建议

### Phase 1：哲学与协议入场

先做：

* `Human Anchor Protocol`
* `Abyss Pressure Protocol`
* `Old Seal Protocol`
* `NarrativeDistortion`
* `AnomalyTrace`

这一阶段还不碰大 UI。

### Phase 2：L4 / L8 / L14 加深

优先强化：

* 地平线层的不确定性与宇宙尺度。
* 海马井的深海分层与封存。
* 玄戒层的旧印、斩谱、净启。

### Phase 3：L6 / L7 / L11 横切增强

让以下对象真正打通：

* 异兆。
* 不可名状保留。
* 深压风闸。

### Phase 4：L12 表面与 SDK 主题包

最后再落：

* `Observatory Pack`
* `Deep Tide Pack`
* `Old Seal Pack`
* 提灯式默认 UI

这个顺序很重要。

因为克苏鲁 inspiration 先是方法论，后才是表面风格。

## 10. 最大风险与对应对策

### 10.1 风险：做成中二皮肤

对策：

默认外观克制、正式；克味集中在协议、结构和深层语义。

### 10.2 风险：系统变冷

对策：

`L5 / L10 / L12` 全部增强人性锚点；任何冷感都不得压过主体性。

### 10.3 风险：用神秘掩盖不足

对策：

所有不可知必须有明确结构对象和原因码，不能当借口。

### 10.4 风险：宿主感到被窥视

对策：

`L6` 感知严格服从授权；`L8` 封存与删除必须真实；`L12` 不调高敏旧痕做“我懂你”。

### 10.5 风险：品牌跑偏

对策：

主品牌保持专业稳重；克苏鲁仅做可选 doctrine / pack / theme。

## 12. 一句话收束

克苏鲁 inspiration 最成熟的加入方式，不是让第二大脑更像怪物。

而是让它更懂：

宇宙比当前更大，时间比现在更深，未知必须被保留，危险知识必须被封存，污染必须斩谱，而宿主的人性与主权必须在这一切之中被更认真、更克制地保护。

再压成最短一句：

让脑学会面对深渊，但永远站在人的这一边。
