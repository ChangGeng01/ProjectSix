# Qinao 发布前 CRITICAL 门禁 Checklist

> 单页发布红线。来自 `QINAO_200_METRICS_RAISED_BAR.md`(提标准定版)中所有 **CRITICAL** 级 GATE。
> **统一规则**:全部勾选 + 对上一出货 never-worse + `data_fp` 指纹匹配 + 评测集污染清洁。**任一未勾即硬阻断发布(BLOCK)。**
> 每条 metric 名可 grep,用于 CI 化(对接 BASEvaluation 回归套件 / verdict.json)。
