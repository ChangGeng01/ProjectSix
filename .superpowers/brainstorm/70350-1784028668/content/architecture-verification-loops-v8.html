八轮破坏性循环 · 修订后设计级通过

1
Cardinality

消除“14=10+4”和 Silicon 第八平面歧义。PASS：四轴独立。

2
Authority & purity

L14 core 只产出 decision、K4 签名；L10/L11 必须检查最终 exact bytes 与每个 provisional chunk。PASS：授权不替代验证。

3
Artifact & capability

结果未知时用 StatePrepare/request + schema/constraints；receipt 后 StateCommit/result digest。PASS：无预知 digest 悖论。

4
Crash & effect saga

K4 与 Zone C 各自本地事务，以 ClaimReceipt/query 关闭 crash gap；含 succeeded_unsealed 与 indeterminate。PASS：不假装跨进程原子。

5
StateABI fallback

exact ABI 或 certified converter；否则丢弃 neural state 并重做 prefill。PASS：无 silent garbage。

6
Thermal & full-blood

热控只能慢、等、停、回收或切等价 backend；QualityIdentity + NeuralExecutionContract 不变。PASS：质量不暗降。

7
Replay & concurrency

snapshot-bound turn、late result 下一 epoch、单 heavy owner、bounded remand。PASS：无回调环与双算语义。

8
Performance evidence

process-cold TTFT、cache-cold prefill、thermally-cold resident decode、end-to-end goodput 分开。PASS：40/30 不混指标。

红队发现后必须锁死的六处修正

Signer truth

当前 Ed25519 seed 是 Keychain at-rest，并非 Secure Enclave non-exportable。硬件根使用可轮换 P-256 suite；envelope 必须 algorithm-agile。

State naming

SemanticStateLake 属 L8/K3；NeuralStateCache 属 L2/K2。现有 `.statelake` tensor reader 不能证明语义湖已实现。

One heavy owner

每 phase 只有一个 authoritative heavy owner；CPU/GPU/NAX/ANE 不是越满越好。nativeV2 丢结果再跑 V1 的双算风险必须消除。

Durable authorization

nonce、issuance、reserve/spend 全部 K4 helper-private、事务持久；DB 丢失或损坏 fail-closed，不能用空账本继续。

Honest placement

requested compute unit 不等于 actual placement。CapabilitySnapshot、certified profile 与 UsageReceipt 分层；未知设备从 quarantine 起步。

Private commitments

ArtifactIdentityCore 用 keyed canonical commitment；随机 payloadRef、signature、receipt 独立成 Storage/Attestation，不参与目标 identity，也不向 trace 暴露裸 digest。

Design consistency · PASS

修订后的抽象规范在八类故障模型下无已知结构矛盾；这只锁定设计。

Current code · REVISE

统一 execution spine、MemoryLedger、durable ledger/outbox、StateABI、typed artifact mesh 等仍未落地。
