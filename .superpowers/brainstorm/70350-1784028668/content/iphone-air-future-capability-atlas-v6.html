40 tok/s：把宣传峰值、冷启动与持续 goodput 分开

34.6

当前 Qwen3.5-4B 满血短冷机最佳量级。距离 40 约 15%，但还不是可承诺通用 cold-40。

15.9

20 分钟末段实测量级。Air 的热稳 30/40 不能靠 scheduler 或 NAX 峰值宣称。

≈25

59 GB/s 与 4-bit 每 target pass 字节量推得的 plain sustained 屋顶量级；更多矩阵峰值不消除权重流量。

>1 token/read

持续跨过带宽屋顶的核心：MTP / ReDrafter / prompt lookup，或训练期减少 bytes/token。

现在 · 无损/可严格认证

固定 MLX + NAX 实证、AOT/prewarm/shape bucket、消灭 host sync、混合 int4、hybrid checkpoint、内容寻址 prefix、任务门控 prompt lookup、热态 never-worse MTP。

需训练 · 真正 30–40+

Qwen 专用 ReDrafter、强化原生 MTP + fused verification、2-bit QAT、KV depth sharing、prompt-level fixed experts / pruning。必须重新做全质量与安全认证。

未来 · 只保留接口

Core AI 成熟路径、EpiCache/KV Prediction、下一代带宽与 cache。未来硬件只能新增 profile，不改 14 层语义和 capability contract。
