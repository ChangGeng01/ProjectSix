v3 · 双网格：更深合作 + 更强隔离

不是让层彼此知道更多内部细节，而是让它们共享更丰富、权限更窄、来源更完整的语义 Artifact。

Zero Trust inside · High bandwidth through artifacts

LayerCore 像细胞：内部实现、可变状态和机制完全私有；外部通过膜交换 claims、evidence、plans、verdicts、permits、receipts。合作强度由 Artifact richness 决定，隔离强度由 Capability precision 决定，两者可以同时增加。

每个 LayerCell 的固定解剖

Ingress Membrane

检查 producer allowlist、schema、capability、epoch、lease、parent digest、sensitivity；按字段生成最小 projection。异常 artifact 进入 quarantine，不送进 core。

→

Pure Semantic Core

只能决定本层拥有的那一种 truth；输入是 projection，输出是新 artifact。不能查 service locator，不能改别层 artifact，不能接触私钥/DB/GPU 除非通过私有 mechanism port。

→

Egress Membrane

计算 digest、传播 sensitivity/taint、记录 parents、附上 determinism 与 expiry；只发布声明过的 artifact 类型。不能自行降低敏感级别。

↓ Private MechanismPort：Kernel / Store / Adapter 的 opaque handle；只属于本层，不可转交其他层

合作语法只有五种，越少越强

1 · Query

读取拥有者发布的 projection；不能直连数据库或读取完整内部状态。

2 · Fan-out / Join

L7/L9 先发布 plan，SpineRuntime 并发调用允许的 ports，再由原 owner reduce。

3 · Proposal / Critique

L9 提案、L10 评价；critique 不能原地修改 candidate，必须发布新 artifact。

4 · Remand

带 target、reason、required proof、maxEpoch；下一 epoch 重入，禁止 callback recursion。

5 · Commit Saga

L13 prepare、L14 authorize、committer execute、L13 reconcile、L14 seal；无一方兼任两种权威。

信息流也有硬边界

Public可进入公开 surface
User Private仅本 session scoped
Sensitive必须投影/脱敏
Sovereign仅 digest/proof 可外露

派生 Artifact 的敏感级别默认取全部 parents 的最高级；任何降级披露必须同时具备 L5 disclosure policy、L11 permit、L14 exact-digest authorization。L3 只能把已经被允许的 projection 编入模型上下文。

四层强制隔离

Compile-time

leaf targets 只依赖 RuntimeCore contracts；BASSovereign 继续不 import Memory/Policy/Orchestration。依赖图与 forbidden-import 测试锁死。

Runtime

default-deny capabilities、opaque handles、session/epoch binding、actor bulkhead、deadline/circuit breaker；无 ambient service locator。

Data

field projection、sensitivity/taint、content-addressed refs；trace/audit 默认只存 digest，Semantic 与 Neural 两座库永不混存。

Failure

FaultArtifact 代替跨层裸异常；L5/L14 缺失 fail-closed，非关键 retrieval lane 可带 coverage 降级；故障不能传播成全局 mutable corruption。

不会因此变慢：Artifact Mesh 传 COW typed value 或 opaque ref，header/digest 只算一次；SpineRuntime 在同一 task 内调用 pure cores，只有 L1/L2/L8/L14 等共享可变/IO 边界发生 actor hop。深度合作增加的是语义连接，不是序列化次数。
