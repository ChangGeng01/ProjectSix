一套系统，七个正交平面

Semantic Authority

L1–L14：谁对哪种“意义/决定”负责。不拥有 GPU/DB/线程。

Kernel Ownership

4 个物理域：机制、隔离、并发、可变运行状态。不产生业务 verdict。

Execution DAG

依赖、fan-out/join、deadline、cancel、skip。不改变语义。

ControlRing

ΩR/ΩG/ΩD/ΩE：epoch、budget、stop、remand。不持有业务状态。

Data Plane

StateLake、NeuralArtifactStore、outbox、ledger 的 bytes/version。不自行决策。

Adapter / IO

MLX、Metal、SQLite、Qinao、tool provider 的机械执行。不 permit、不绕 gate。

Observe / Replay

trace、metric、receipt、replay digest。不隐式回流同轮。

七次运行后的快路与闭环

Verified semantic hit

L7 只检查 dependency versions；L9 命中；L10 用 receipt digest/epochs O(1) 验证；L11/L12/L13/L14 仍运行。L2/L3 发 typed Skipped，不被强制唤醒。

Multi-turn KV / prefix hit

L3 semantic/stable-prefix fingerprint 与 model、adapter、quant、tokenizer/template、session generation 全匹配才恢复。只加速 L2，绝不跳过 L9–L14。

Thermal serious+

L1 仅阶段 checkpoint；L2 在 hot loop 内读取本地原子状态并 MTP→plain。不能降低模型质量或偷偷截短；需要改变语义预算时返回下一 epoch remand。

High-risk tool / streaming

正文只生成一次并写 content-addressed spool；同一字节通过 L10/L11/L14 后释放。高风险过程中只允许 typed progress，partial tool JSON 不得流出或执行。

Evidence conflict

L7 处理 evidence-set 冲突；L10 处理 candidate-claim 冲突。Remand 通过 ΩG/ΩD 下一 epoch，次数耗尽则澄清/拒答，不产生代码级回调环。

Tool receipt → next turn

只有 sealed receipt 才能变成新的 typed InputEvent；携带 causation、depth、idempotency cursor。模型只看脱敏 projection，receipt 本身不能自动生成下一 ToolIntent。

一层一真相每种 semantic decision 只有一个 writer；其他层只能引用 artifact。
合作不等于全唤醒每轮走依赖 DAG；可安全跳过的层必须留下 typed SkipReceipt。
Actor 是实现细节只在共享可变/IO 边界 actor 化；pure layer core 在同一 task 内值调用。
